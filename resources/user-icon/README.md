# جای گذاشتن آیکون برنامه

تصویر آیکون را **همین‌جا** بگذارید. سه نکته:

1. **اسم فایل مهم نیست** — هر اسمی داشته باشد پیدا می‌شود (`png`، `jpg` یا `webp`).
2. **فقط یک تصویر** این‌جا باشد. اگر دو تا باشد، اسکریپت عمداً خطا می‌دهد تا
   اشتباهی آیکون غلط منتشر نشود.
3. تصویر **مربع** باشد، حداقل ۱۰۲۴×۱۰۲۴، و دور طرح اصلی حدود **۱۵ تا ۲۰ درصد
   حاشیه‌ی خالی** داشته باشد — چون ماسک دایره‌ای اندروید حدود ۲۱٪ از لبه‌ها را
   می‌برد.

بعد از گذاشتن فایل:

```
npm run icons:android    # تولید همه‌ی سایزها
npm run preview:icons    # پیش‌نمایش چهار شکل ماسک، برای اطمینان از نبود بریدگی
```

رنگ پس‌زمینه‌ی آیکون تطبیقی خودکار از چهار گوشه‌ی همین تصویر خوانده می‌شود، پس
لبه‌ی ماسک اصلاً دیده نمی‌شود.
